# TechCorp Employee Handbook (excerpt)

Welcome to TechCorp! This handbook summarises a few day-to-day policies.

## Working hours
Core hours are 10:00-16:00 local time. Flexible start/finish around those hours
is fine as long as you keep your calendar current.

## Help desk
For IT issues, open a ticket in the portal or message #it-help. Password resets
are self-service at https://portal.techcorp.local/reset.

## Security basics
- Never share your password or MFA codes.
- Report anything suspicious to security@techcorp.local.
- Use the shared drive, not personal email, for internal documents.
